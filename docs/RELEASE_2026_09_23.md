# September 23, 2026 release

This release extends the homepage's restrained motion to the other page heroes, simplifies selected copy, reduces excess space in Contact, and makes the Contact email row copy the address instead of opening an email application.

## Changes

- Short, one-time SVG/CSS motion for the homepage and page-specific hero marks. Decorative final states remain visible without JavaScript, IntersectionObserver, or motion enabled.
- Astro navigation lifecycle handling, restrained hover/focus movement, and reduced-motion support.
- Compact desktop/tablet Contact hero; original contact-row styling and hover behavior retained. Clicking or keyboard-activating the email row copies the address, briefly shows “Copied”, and announces success. Clipboard errors show manual-copy guidance.
- Light copy cleanup, “Builder first” without a period, “Let's talk” with lowercase t, and the requested Services wording.
- Existing route history, authored Manager README/blog content, claims, navigation, dependencies, and analytics configuration preserved.

## Validation

- Production build: all 26 routes generated. 722 links and 219 asset references pass the static audit, including metadata, canonical URLs, fragment targets, and duplicate IDs. Sitemap and custom-domain checks pass.
- Chromium: 88 responsive layout checks across all routes, including nine main pages at 1440, 1024, 900, 720, 390, and 320px and 17 articles at desktop/narrow mobile widths. No horizontal overflow, missing image descriptions, or browser page errors.
- Firefox and WebKit: 36 additional desktop/mobile layout checks, working email copying, and reduced-motion checks passed with no page errors. The matching installed Playwright 1.58.2 runner was used for these browsers.
- All nine hero treatments finish without loops; 27 reduced-motion/no-JavaScript/missing-observer cases preserve final states. Homepage process/engagement motion and dynamic reduced-motion changes pass.
- Keyboard focus, mobile menu and Escape/focus return, Astro route transitions, four README anchors and active state, Services hover, consulting-specific chrome, and all 54 loaded book covers pass.
- Contact copying passes real clipboard readback, mouse, touch, Enter/Space, return navigation, transient feedback, denied/missing Clipboard API, and no-JavaScript fallback checks.
- Independent implementation and content reviews found no actionable release defects. Desktop/mobile screenshots were reviewed.

Automated browser checks do not constitute full assistive-technology or physical-device certification. Analytics requests were blocked during QA; analytics-console receipt is not claimed. The previously documented toolchain advisories and CI Node maintenance remain separate; this release adds no dependencies.
