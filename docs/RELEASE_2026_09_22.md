# September 22, 2026 release

This release publishes the reviewed homepage and supporting-page updates, adds the dedicated `/consulting/` landing page, and fixes invisible Bookshelf cards on mobile.

## Changes

- Shared headline and the reviewed section order, typography, spacing, colors, portrait, and navigation.
- Standalone consulting page with the reviewed black hero, employer/client strip, three body sections, and contact CTA. No menu or footer; the main homepage and `/services/` remain separate.
- All 54 Bookshelf cards render without an animation dependency. The old grid-level intersection threshold could never be reached on narrow screens.
- Content is visible by default; optional fades observe individual items and respect reduced motion. Observers and menu listeners are cleaned up during route changes.
- Mobile-menu controls, current-page state, Escape handling, focus return, and a no-JavaScript navigation fallback.
- Shared metadata/font/analytics head, current homepage metadata, smaller dedicated landing stylesheet, and removal of retired Manager README styles.

## Validation

- Production build: 26 pages, with all 25 prior routes preserved.
- Built HTML: 723 links and 219 asset references checked; no missing internal destinations or anchors, duplicate IDs, missing metadata, or incorrect canonical URLs. One H1 per page.
- Nine main routes at 320, 390, 768, 1024, 1280, and 1440px; no horizontal overflow. All 17 articles also checked at 320 and 1280px.
- Desktop/mobile screenshots reviewed; all 54 Bookshelf cards visible. Mobile menu, Escape/focus return, current-page state, README anchors, landing contact anchor, and navigation between layouts checked.
- Existing Google Analytics configuration retained. Analytics-console receipt and a full assistive-technology or physical-device certification are not claimed.

## Separate maintenance

The dependency audit reports 14 toolchain advisories (1 critical, 12 high, 1 low). Full remediation requires a major Astro upgrade and remains separate from this visual release. This deployment consists of static files on GitHub Pages, with no Astro server, server islands, or image-optimization endpoint exposed. That reduces runtime exposure; it does not certify the dependencies as vulnerability-free.

## Release and rollback

GitHub Pages builds and deploys on a push to `main`. The pre-release production commit is `154bab01d38cf0590d03c4ec92e498f51d9bf355`. Preserve history: roll back by reverting the release commit and redeploying, rather than force-pushing an old branch tip. Deployment results are recorded in the release task and GitHub Actions.
